ODPL Incubator Offline-Only Verification

✅ Offline-Only Configuration

This test verifies that the ODPL Incubator site is configured to work entirely offline without any API calls to Directus.

🔍 What to Check

  1. Open Browser Developer Tools (F12 or right-click → Inspect)
  2. Go to the Network tab and clear any existing requests
  3. Navigate to the main site (index.html)
  4. Check the Network tab - you should see NO requests to:
    • directus.thegovlab.com
    • unpkg.com/@directus/sdk-js
  5. Check the Console tab - you should see messages like:
    • "Loaded mentors from local JSON file (offline mode)"
    • "Loaded participants from local JSON file (offline mode)"
    • "Loaded press from local JSON file (offline mode)"
    • "Loaded FAQ from local JSON file (offline mode)"
    • NO "trying API..." messages

🧪 Test Press Page

Test the press page to ensure it also works offline:

⚠️ Expected Console Messages

When working correctly, you should see these messages in the browser console:

Loaded mentors from local JSON file (offline mode) Loaded participants from local JSON file (offline mode) Loaded press from local JSON file (offline mode) Loaded featured press from local JSON file (offline mode) Loaded FAQ from local JSON file (offline mode) Loaded alerts from local JSON file (offline mode)

❌ Error Messages (If Something Goes Wrong)

If the site tries to make API calls, you'll see error messages like:

ERROR: Local mentors data not available. This site requires offline data to function. Please ensure mentors-local.json exists in the data directory.

🔧 Files Modified for Offline-Only Operation

  • js/scripts.js - Removed API calls, only loads from local JSON
  • index.html - Removed Directus SDK import, added DATA_PATH
  • press/index.html - Removed Directus SDK import, added DATA_PATH
  • data/*.json - Sample data files for offline use

📁 Data Files Created

  • data/mentors-local.json - Mentor data
  • data/participants-local.json - Participant data
  • data/press-local.json - Press articles
  • data/featured-press-local.json - Featured press articles
  • data/faq-local.json - FAQ data
  • data/alerts-local.json - Alert banner data

✅ Verification Complete

If you see the expected console messages and no API calls in the Network tab, the site is successfully configured for offline-only operation!
